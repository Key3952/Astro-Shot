# Оптимизация экрана «Обзор», GPS локация, города Северо-Запада и Интерактивная карта облачности

Комплексное обновление приложения AstroShot: гармонизация размеров главного экрана «Обзор» для мгновенной видимости ключевых карточек, интеграция определения реальных координат по GPS по нажатию кнопки, расширение каталога городов Северо-Запада РФ и внедрение интерактивной карты облачности и осадков с поддержкой нескольких провайдеров (OpenWeatherMap, Open-Meteo, RainViewer).

### User Review & Critical Decisions

> [!IMPORTANT]
> - **Оптимизация экрана «Обзор»**: Сохраняем привычную структуру и все блоки (Индекс качества неба, Луна, Окно темноты, Сияния, Оптика), но оптимизируем высоту и пропорции кругового индикатора (размер уменьшен с огромного до аккуратного 64dp компактного бейджа в единой строке заголовка карточки), благодаря чему на экране смартфона сразу видны все ключевые карточки без ощущения пустоты.
> - **Поиск по GPS**: Определение координат запускается **только при нажатии на кнопку локации/GPS**, с запросом стандартных системных разрешений `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` и авто-подстановкой ближайшего населенного пункта или точных координат.
> - **Города Северо-Запада России**: Добавлены Санкт-Петербург, Мурманск, Териберка, Петрозаводск (Карелия), Сортавала (Ладога), Кировск (Хибины), Архангельск, Великий Новгород, Псков, Выборг, Вологда, Сыктывкар с их шкалой Бортля засветки.
> - **Мульти-провайдерная интерактивная карта**: Интерактивная карта облачности и осадков с переключением слоев (Общая облачность, Осадки/Радар, Ветер, Температура) и поддержкой бесплатных источников:
>   1. **Open-Meteo** (работает прямо из коробки без ключей и без ограничений в РФ).
>   2. **RainViewer Radar API** (бесплатные радарные снимки осадков и облаков в реальном времени, не требует ключа).
>   3. **OpenWeatherMap 2.5 / 3.0** (поддержка ввода бесплатного ключа пользователя с получением тайлов облачности `clouds_new` и осадков `precipitation_new`).
>   4. Режим сравнения/усреднения показателей облачности между источниками.

### 1. Overview & Core Concept

- **Решаемая задача**: Устранить избыточный масштаб виджета индекса на первом экране, дать фотографу возможность в 1 клик определить свои точные полевые GPS-координаты, выбирать популярные точки съёмки на Северо-Западе (где чаще всего ловят северные сияния и белые ночи) и визуально оценивать движение облачных фронтов на интерактивной карте.
- **Целевая аудитория**: Ночные пейзажные фотографы, охотники за полярными сияниями в Карелии и на Кольском полуострове, астрономы-наблюдатели.

---

### 2. User Experience & Visual Design

1. **Экран «Обзор» (Dashboard)**:
   - Верхняя карточка «Качество неба»: компактный сбалансированный заголовок с аккуратным мини-индикатором счета (64dp), текущей облачностью, температурой и риском росы.
   - Под карточкой сразу видны: блок текущей фазы Луны с диском, окно астрономической темноты и радар полярных сияний без необходимости длинной прокрутки.
   - В шапке приложения: кнопка геолокации с моментальным запуском GPS-поиска и индикатором точности.
2. **Диалог выбора локаций (Города СЗФО)**:
   - Вкладка быстрых пресетов разделена по регионам: Северо-Запад (СПб, Ленобласть, Мурманск, Териберка, Хибины, Карелия, Архангельск), Кавказ, Алтай, Байкал, Крым, Центр и Сибирь.
   - Большая кнопка «Определить моё местоположение по GPS» с индикатором текущих координат.
3. **Интерактивная карта облачности и осадков (Новый инструмент)**:
   - Интерактивный просмотрщик карты с масштабированием и перемещением по координатам выбранного города/GPS.
   - Селектор слоев: «Облачность», «Осадки (Радар)», «Ветровые потоки», «Спутниковый слой».
   - Селектор источника данных: Open-Meteo, RainViewer Radar, OpenWeatherMap (с полем ввода бесплатного API-ключа в настройках карты).
   - Инструкция прямо в приложении: как за 1 минуту бесплатно зарегистрировать API-ключ OpenWeatherMap.

### 3. Key Product Decisions & Trade-Offs

- **Решение 1: Встроенный Compose-просмотрщик интерактивных тайлов карты**:
  - *Выбор*: Использование легковесного интерактивного рендерера тайлов (slippy map tiles: OSM + слои погоды RainViewer и OpenWeatherMap) с жестами зума и панорамирования (pinch-to-zoom & pan).
  - *Почему*: Не требует тяжелых внешних Google Maps SDK с привязкой к кредитным картам, полностью доступен и стабильно работает в РФ.
- **Решение 2: Безопасное хранение пользовательского API-ключа в SharedPreferences**:
  - *Выбор*: Пользователь может ввести свой бесплатный ключ OpenWeatherMap в интерфейсе карты, он сохраняется локально на устройстве и немедленно активирует тайлы высокого разрешения. Если ключа нет — автоматически активен бесплатный RainViewer и Open-Meteo без каких-либо настроек.
- **Решение 3: Определение координат через стандартный Android LocationManager**:
  - *Выбор*: Использование системного `LocationManager` (GPS_PROVIDER / NETWORK_PROVIDER) с запросом runtime-разрешения.
  - *Почему*: Работает на 100% устройств без жесткой привязки к Google Play Services и без сбоев в отдаленных регионах.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   AstroShot UI                         │
│  ┌──────────────────┬───────────────────────────────┐  │
│  │ TopBar: GPS btn  │ Dialog: NW Russia presets     │  │
│  └──────────────────┴───────────────────────────────┘  │
│  ┌──────────────────┬───────────────────────────────┐  │
│  │ Compact Dashboard│ Interactive Cloud Radar Map   │  │
│  │ (Optimized scale)│ (RainViewer / OWM / OpenMeteo)│  │
│  └──────────────────┴───────────────────────────────┘  │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                    AstroViewModel                      │
│ - GPS LocationProvider (LocationManager on-demand)     │
│ - WeatherMapRepository (Tile URLs, Radar frames)       │
│ - Multi-source aggregator (Clouds & Dew comparison)    │
│ - Expanded NW Russia Location Catalog                  │
└────────────────────────────────────────────────────────┘
```

- **Новые сущности**:
  - `WeatherMapLayer`: CLOUDS, PRECIPITATION_RADAR, WIND, TEMPERATURE.
  - `WeatherMapProvider`: RAINVIEWER (бесплатно без ключа), OPEN_METEO (бесплатно), OPENWEATHERMAP (с ключом).
  - `LocationProvider`: получение текущей широты/долготы через GPS по требованию.
